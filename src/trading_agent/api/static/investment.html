Net unrealized P&L is estimated liquidation value less that remaining basis.

      What is not calculated here

        Allocation targets, sector charts, portfolio benchmarks and return curves remain unavailable until their data and calculation contracts are implemented. Missing metrics are not zero.

        Historical research is available through the CLI

        This screen does not launch a job, show invented results or imply that current research ranks were backtested. Run the existing isolated workflow against reviewed inputs, then inspect its recorded report.

        Before interpreting a result

        • Use only data and universe membership that were available at each decision time.
        • Keep fees, slippage, liquidity, corporate actions, dividends and failed orders in the result.
        • Separate training and evaluation periods. Repeatedly choosing parameters on the test period introduces selection bias.
        • A historical or simulated return does not establish future profitability or broker acceptance.
