      Local registration and CLI help

      Input paths are chosen by the local operator through the CLI. Browser requests accept only registered resource identifiers and their reviewed hashes. The browser never accepts a filesystem path or downloads market data.

      Run .venv/bin/trading-agent register-backtest --help for the local registration command and .venv/bin/trading-agent daily-backtest --help for the existing direct research workflow.

      Run the command from the repository folder, inspect its validation output, then refresh this page. Registration does not start a job or change a paper account.

      • Keep source dates, current-constituent bias, corporate actions, dividends and failed orders explicit.
      • Use chronological holdouts. Choosing parameters on a test period can overstate results.
      • Paper simulation and synthetic fixtures do not certify broker execution or real-market profitability.
