What needs attention

    Inspect the evidence

    Read these results correctly

    Real quotes, virtual execution
    Later observed quote clocks, adverse tick prices, available depth and delivery costs determine simulated fills. Daily candle closes never fill orders.
    Incomplete outcomes remain visible
    Open positions, orders, unpaid claims and coverage gaps are preserved. An exit request is not a completed liquidation.
    Labels and portfolio returns differ
    Each label uses its own starting virtual cash. Summing independent label P&L does not measure a feasible portfolio or shared capital allocation.
    Validation is chronological
    Whole-session splits purge overlapping outcome intervals, embargo neighboring data, fit scalers on training only and calibrate separately. Frozen holdout checks cannot authorize live trading.
